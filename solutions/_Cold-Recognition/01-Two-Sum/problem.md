## Problem (plain English)
Given an array `nums` and a target `target`, return the **indices** of the two numbers
that add up to `target`. Exactly one solution exists; you may not use the same element
twice. Return them in any order.

## Examples
| nums | target | answer |
|---|---|---|
| [2,7,11,15] | 9 | [0,1] |
| [3,2,4] | 6 | [1,2] |
| [3,3] | 6 | [0,1] |

## Constraints
- `2 ≤ nums.length ≤ 10^4`,  `-10^9 ≤ nums[i], target ≤ 10^9`
- Exactly one valid answer. Aim to beat O(n²).
