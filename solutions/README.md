# solutions/

Your code lives here, organized by curriculum module so the mentor (and you) can find
and re-run it. Suggested layout:

```
solutions/
  M2-arrays-hashing/
    two-sum.py
    group-anagrams.py
  M4-sliding-window/
    longest-substring-no-repeat.py
  M11-linked-lists/
    reverse-linked-list.py
```

Conventions:
- One file per problem. Name it after the problem in kebab-case.
- Put the problem URL and your final time/space complexity in a comment at the top.
- A problem only counts as **solved** once it's accepted on the judge (LeetCode etc.),
  not when the mentor approves it. Tommy can run code here to check behavior, but the
  judge is the final word (see `CLAUDE.md` §16).

The commit history of this repo is your real progress log — every solve, level change,
and revision is captured by `/endsession`.
