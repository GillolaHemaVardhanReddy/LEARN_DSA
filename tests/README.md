# tests/ — cold, closed-book. The ONLY path that promotes L4 → L5.

| Folder | What | Cadence |
|---|---|---|
| `checkpoints/<NN-topic>-<date>/` | the Friday topic checkpoint: (1) disguised + seeded statement → pattern + trigger + complexity-with-the-work · (2) template / core loop from memory · (3) one unseen medium coded cold → LC. Plus 2 cards from older topics. | every Friday |
| `mixed/<date>-…/` | mixed recognition tests (cards only, no coding) + the historical gauntlets: `2026-06-gauntlet-24q`, `2026-06-cold-recognition`, `2026-08-comeback-gauntlet` (Q10–Q20 still open) | monthly 10-Q · daily 1–2 cards via RECALL |
| `contests/<date>-<contest>/` | one upsolve per contest + notes; from month 3 also timed 4-problem simulations | after every contest |
| `interviews/<date>/` | mock interviews with a hire / lean-hire / no-hire call | month 7, then monthly |

**Rules:** fresh disguised statements, never LC titles · every statement seeded with 2–3 input→output lines · adjacent-family traps on purpose · **no answer key in the folder** · marks only during the run, full reveal after the last question · help costs signal and is logged · the **disqualifier gate** (contiguous? sorted/may sort? order or membership? count/best/list-all?) is spoken before any tool is named.
