# PHASE 1 — Linear / Array patterns (M1–M7)

Self-contained folder for everything in Phase 1. **Phase 2 copies this exact skeleton.**

```
phase-1/
├── syllabus.md     ← patterns covered (M1–M7) + status + what's owed
├── mistakes.md     ← every Phase-1 mistake: root cause + re-test
├── notes/          ← study notes per pattern (00–07)
├── learn/          ← first-time guided solves (brute→bridge→optimal)
├── practice/       ← per-pattern rep sets (easy/medium) + solo L4 gates
├── drills/         ← 01-mixed-gauntlet · 02-monotonic-stack · 03-hard-gauntlet
└── test/           ← cold closed-book recognition (the L4→L5 path)
```

Live cross-phase tracking stays at the repo root: `COMMAND_CENTER.md` (front door),
`PROGRESS.md` (levels), `REVISION_QUEUE.md` (spaced repetition), `PATTERN_JOURNAL.md` (cues),
`LEARNING_PROFILE.md`, `CLAUDE.md` (operating manual), `CURRICULUM.md` (full 24-module master).
