> Correct instinct — and the ORDER matters.

---

## ⚠️ THE ORDER IS THE POINT — test BEFORE revising

Revise first and the test only measures short-term echo. Test first and we get a **true decay reading**:
which patterns survived a month, which evaporated. Then we spend repair time ONLY where it leaked.

```
PART A — RECOGNITION TEST   (cold, closed-book, TEST mode)   ← measures decay
        ↓  score it honestly
PART B — REVISION           (closed-book recall, repair only where A failed)
        ↓
PART C — RE-TEST the failures cold, +3d later
```

---

## PART A — how it runs (`PART-A-recognition-20Q.md`)

- **20 disguised problem statements**, interleaved across all 10 learned patterns. No topic labels,
  no LeetCode titles — the titles are half the answer, so they're stripped.
- **NO CODING.** For each question, boss gives exactly three things:
  1. **The pattern** (name it)
  2. **The trigger** — the surface feature in the statement that fired it (one line, his words)
  3. **Target complexity** (time + space) — this is the M1 check, folded in
- **~2 minutes per question.** First instinct matters more than a polished answer — that's what
  recognition IS. If he needs 10 minutes to reason it out, it's not L5.
- **TEST MODE = no help.** Kira gives zero hints during Part A. Asking costs signal and gets logged.
- **No answer key in this folder** (standing drill rule). Scoring happens live, question by question.
- Some questions are **traps** — the obvious surface pattern is the wrong tool. That's deliberate;
  the traps are worth more than the gimmes.

### Scoring (per question)
| Mark | Means |
|---|---|
| ✅ **FULL** | pattern + trigger + complexity, all correct, first instinct |
| 🟡 **PARTIAL** | right pattern, fuzzy trigger OR wrong complexity OR needed a long think |
| ❌ **MISS** | wrong pattern, or blank |

**Bar:** ≥17/20 FULL ⇒ recognition survived the layoff, we move straight to M11 Linked Lists.
14–16 ⇒ targeted repair on the misses only. ≤13 ⇒ full Part B sweep before any new topic.

## PART B — revision (`PART-B-concept-recall.md`)

Closed-book concept recall, **run only on what Part A exposed** + the 6 overdue queue items
(all 23–29 days overdue as of 2026-08-09). Reconstruct before revealing — always.

## PART C — re-test

Every ❌ and 🟡 from Part A gets a **fresh, different** problem on the same pattern, cold, +3d out.
A repaired pattern isn't repaired until it's named cold on a statement he hasn't seen.
